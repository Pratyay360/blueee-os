Installation & Usage Guide

1

Download ISO or Scan QR

Download directly to your PC or scan the embedded QR code on your smartphone/tablet to save the ISO.

balenaEtcher / Rufus / dd
2

Flash to USB Drive

Use Rufus (in DD mode), balenaEtcher, or Fedora Media Writer to write the downloaded ISO to a USB flash drive.

sudo dd if=image.iso of=/dev/sdX bs=4M status=progress
3

In-place Rebase (Alternative)

Already on Fedora Silverblue, Kinoite, or an Atomic spin? You don't need to reinstall. Rebase directly via rpm-ostree.

sudo rpm-ostree rebase ostree-unverified-registry:...
4

Cosign Verification

All container builds are cryptographically signed using Cosign and verified against the repository public key.

cosign verify --key cosign.pub ghcr.io/...
